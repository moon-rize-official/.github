# Moon Rize

**Moon Rize designs and builds software, websites, infrastructure and creative tools for artists, DJs, collectives, festivals and independent communities.**

Moon Rize sits between underground culture and technical craft: building event platforms, community systems, operational tooling, digital products and the infrastructure needed to keep them reliable.

**Website:** [moon-rize.de](https://moon-rize.de)

## What we build

- **Websites and digital products** — public experiences, project sites and community-facing applications.
- **Community systems** — practical tooling for events, collaboration and organized community operations.
- **Creative utilities** — focused tools for artists, DJs, producers and organizers.
- **Engineering platforms** — reproducible workstations, development tooling, infrastructure and deployment systems.
- **Documentation and standards** — durable operating knowledge that keeps projects understandable and maintainable.

## Engineering principles

- Keep canonical state in the repository or system that owns it.
- Prefer reproducible configuration over undocumented manual setup.
- Keep credentials and private recovery material out of source control.
- Require verification for consequential changes.
- Preserve provenance when systems, names and repositories are migrated.
- Keep repositories focused on one clear lifecycle and authority boundary.
- Use `moonrize-*` for newly created machine-readable Moon Rize identifiers.

## Organization repositories

The organization is structured around clear repository responsibilities, including:

- architecture and decision records;
- platform/infrastructure desired state;
- operating-system image construction;
- bare-metal provisioning;
- workstation configuration;
- developer tooling;
- website and product source;
- canonical brand assets;
- organization documentation;
- shared automation utilities.

Repository-specific documentation defines the exact authority and lifecycle boundary of each project.

## Contribution

Organization-wide contribution, security, issue and pull-request standards are maintained in this `.github` repository and inherited by repositories that do not define stricter local policies.

## Brand

Human-facing organization name: **Moon Rize**.

The existing public domain remains **moon-rize.de**.

Technical identifiers created for Moon Rize resources use the `moonrize-*` prefix.
